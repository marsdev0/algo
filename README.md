# algo

LeetCode 刷题仓库，Python 实现，按题型分类组织。

## 环境与运行

- Python 3.13+，使用 [uv](https://docs.astral.sh/uv/) 管理依赖，src layout（项目本身以 editable 方式安装进虚拟环境）
- 运行某一题：`uv run python -m algo.<题型>.lc_<题号>`（文件内加 `if __name__ == "__main__":` 自测）
- 也可在代码中导入：`from algo.<题型>.lc_<题号> import Solution`

## 目录约定

- 每题一个文件（平铺）：`src/algo/<题型>/lc_<题号>.py`，题号补零到 4 位（如 `lc_0034.py`）
- 同一题的多种解法或本地测试代码，在同一题型包下新增文件
- 题型包的 `__init__.py` 存放该题型的通用模板（如 `binary_search` 的三个二分模板）
