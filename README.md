# algo

LeetCode 刷题仓库，Python 实现，按题型分类组织。

## 环境与运行

- Python 3.13+，使用 [uv](https://docs.astral.sh/uv/) 管理依赖，src layout（项目本身以 editable 方式安装进虚拟环境）
- 运行某一题：`uv run python -m algo.<题型>.lc_<题号>.solution`
- 也可在代码中导入：`from algo.<题型>.lc_<题号>.solution import Solution`

## 目录约定

- 每题一个目录：`src/algo/<题型>/lc_<题号>/solution.py`（题目目录无需 `__init__.py`）
- 同一题的多种解法或本地测试代码，放在该题目录内新增文件
- 新开一个题型时，在 `src/algo/` 下新建包目录并放一个空的 `__init__.py`
